# MASTER CODEX PROMPT — AI DAG CODE AGENT PLATFORM

You are a senior software architect and implementation engineer.

Build this project completely from scratch as a production-quality prototype that can later be deployed to Hugging Face Spaces.

Do not give me only explanations or pseudocode. Implement the complete working project with source code, configuration, Docker setup, tests, documentation, and a clean frontend.

The system is an AI-powered coding agent that takes a user's natural-language prompt, creates a DAG execution plan using an LLM, generates code and tests through separate LLM agents, runs the code inside an isolated Docker container, performs static analysis, retries failed code, and finally returns the validated result to the user.

---

# 1. CORE PRODUCT

The application should work like a Claude-style coding interface.

User opens the website.

User enters their own LLM API key.

User enters a natural-language coding prompt.

User can optionally select a model/provider.

The system automatically determines the provider when possible.

Then:

1. LLM Planner creates a DAG.
2. DAG engine executes the DAG.
3. Agent-1 generates code.
4. Agent-2 generates tests.
5. Static analysis runs.
6. Docker execution runs.
7. Tests are executed.
8. If everything passes, return the final code/result.
9. If tests fail, send failure information back to the code-generation agent.
10. Generate repaired code.
11. Generate/revise tests.
12. Run static analysis again.
13. Run inside Docker again.
14. Repeat up to 4 repair retries.
15. If still failing after the retry limit, return the best result plus failure information.

The system must visibly stream workflow progress to the frontend.

* unique node IDs
* dependency existence
* no circular dependency
* valid node type
* all nodes reachable
* valid JSON schema
